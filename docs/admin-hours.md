# 後台 · 營業時間 規則（2026-10-26）

原本寫在頁面上的說明文字移到這裡，日後看要不要用。程式在 `src/pages/AdminHoursPage.tsx`。
週六日固定不營業，不用列。

## 版面

- **左：「假期 & 休息日」月曆**（設計同前台日曆，單月、大數字），整合三種日期：
  - **休息日**（`closed_dates`，kind＝活動／大總評／其他）：學會自己的不營業日。黃色。
  - **法定假日**（`closed_dates`，kind＝holiday）：進後台時自動匯入（`autoImportHolidays`，今年＋明年）。藍（cyan）。
    刪除＝學會當天照常營業，之後不會再被自動補回。
  - **寒暑假封鎖**（`rental_blackouts`）：區間內學生不可租借，前台日曆灰化、`submit_orders` 擋單。灰色。
- **右：值班時間表**（`staff_duties`）：週一～五 × 午班／晚班。

## 休息日／法定假日的效果

與週末相同：待繳押金倒數與逾期天數跳過、當天到期的歸還順延到下一個營業日。
新增休息日（今天以後）自動發全站公告 template（「10/16（週五）系學會因大總評公休，當天不提供借用與歸還服務。」，
**Facebook 請同步發布**），並通知當天取件或歸還期限因此順延的同學；補登過去的日期不發。
刪除休息日不會收回已發出的公告。

## 寒暑假封鎖

擋新單（學生不可選封鎖區間內的日期；admin／staff 不受限）。新增後通知與區間重疊的進行中訂單。
延期不得延入封鎖期（rental-rules）。

## 月曆操作

- 點任一天：在日期右側開小視窗。
  - 那天沒東西 → **新增休息日**：日期（唯讀）、原因（活動／大總評／其他），選「其他」才多一個說明欄。
  - 那天是休息日／法定假日 → 顯示內容，可**刪除**。
  - 那天在封鎖期內 → 顯示區間，可**刪除整段**。
- 標題右側「新增」下拉：
  - **休息日**：提示點月曆日期（同直接點日期）。
  - **寒暑假**：在月曆上點起日、訖日（區間反白），下拉處變成「確定」；沒有小視窗。原因固定寫「寒暑假」。

## 值班時間

- 值班時段＝營業時間：學生選大量設備繳押金／取件時段（`duty_slots` RPC）、經手人選單把當下值班者排前、前台 Info 視窗的營業時間，都讀這裡。
- **午班 12:00–13:00、晚班 17:00–19:00**（寫死在 `AdminHoursPage.tsx` 的 `SHIFTS`，學會要改時間再做成設定）；
  舊資料依開始時間歸類（15:00 前＝午班）。
- 每格 **1～3 人**，名單＝會員管理裡身份為系學會的人；同一人可排多個時段。
- 按「編輯」才能改，按「確定」一次寫入差異（移除的刪、新增的加），之後表格鎖定；取消＝丟棄。
- **值班表在開放租借前一定排好**（2026-10-02 Bernard 確認），不用擔心起租日沒有值班時段。
